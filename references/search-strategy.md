# Стратегия поиска, скачивания и верификации русскоязычных источников

## 1. Приоритетные открытые площадки (РФ)

### А. Теория, методология, научные статьи (PDF с текстовым слоем)
1. **КиберЛенинка (`site:cyberleninka.ru`)** — главный источник открытых статей ВАК/РИНЦ.
   - Страница статьи: `https://cyberleninka.ru/article/n/<slug>`.
   - Прямой PDF: `https://cyberleninka.ru/article/n/<slug>/pdf` (или мета-тег `citation_pdf_url` на HTML-странице).
2. **Открытые архивы журналов и вузов:**
   - Вестники МГУ, СПбГУ, ВШЭ (`wp.hse.ru`, `vgmu.hse.ru`, `foresight-journal.hse.ru`), РАНХиГС, Финансового университета, УрФУ, ТГУ (`journals.tsu.ru`), НИУ ИТМО, «Вопросы экономики», «Экономическая политика», «Мониторинг общественного мнения» (`monitoringjournal.ru`).
   - Поиск прямых PDF: `"<ключевые термины>" filetype:pdf site:.ru 2021..2026`.
3. **Научные агрегаторы и открытые репозитории:**
   - OpenAlex / Crossref API (поиск по русскоязычным статьям с `open_access.oa_url`), `dissercat.com` (авторефераты), `elibrary.ru` (только открытые аннотации/PDF без платных стен).
4. **Нормативно-правовые акты (НПА — для права, экономики, госуправления):**
   - `pravo.gov.ru`, `consultant.ru`, `garant.ru`, `minfin.gov.ru`, `cbr.ru`.
5. **Классики / монографии (старше `min_year`):**
   - Строго в рамках квоты `max_classic_sources` (обычно 2–4 работы) и **только** при наличии скачанного файла/верифицированного текста с точными выходными данными.

### Б. Эмпирика, статистика и реальные кейсы (для 2-й / практической главы)
- **Официальная статистика и социология:** `rosstat.gov.ru`, `cbr.ru`, `wciom.ru`, `fom.ru`, `mediascope.net`, `akarussia.ru`, `datainsight.ru`, `nafi.ru`.
- **Индустриальные кейсы с цифрами:** `sostav.ru`, `adindex.ru`, `vc.ru`, `rbc.ru`, `kommersant.ru`, `habr.com`, `t-j.ru`, годовые отчёты публичных компаний (`ir.*`, раскрытие информации).
- **Контр-кейс (для методологического сравнения в § 2.2):** целенаправленно найди 1–2 кейса/исследования, где использовалась контрольная группа, A/B-тест, эконометрическая панель или независимый аудит.

## 2. Поисковая матрица (4–6 запросов)

Формируй запросы по 4 корзинам, чтобы база покрывала всю структуру работы:
1. **Понятийный аппарат и классификации** (`site:cyberleninka.ru "<термин>" классификация понятие 2021..2026`).
2. **Методики оценки, метрики, модели** (`site:cyberleninka.ru "<термин>" методика оценка эффективность критерии`).
3. **Свежая российская статистика и регуляторика** (`"<отрасль>" статистика 2024 2025 Росстат OR ВЦИОМ OR Mediascope OR ЦБ`).
4. **Практический кейс + контр-кейс** (`"<компания/отрасль>" кейс результаты цифры конверсия OR охват OR выручка site:sostav.ru OR site:vc.ru OR site:adindex.ru`).

## 3. Правила отбора, скачивания и обработки блокировок

1. **Запас +30%:** качай на 5–7 материалов больше минимума (`min_sources`), поскольку 15–25% найденных PDF окажутся сканами без текстового слоя, короткими 2-страничными тезисами или дубликатами.
2. **Автоматическая валидация через `fetch_sources.py`:**
   - PDF должен начинаться с `%PDF-`, весить > 30 КБ и содержать > 1 000 символов кириллицы (если < 300 символов — это скан-картинка, отбраковывается автоматически).
   - Для каждого сохранённого `.pdf` / `.txt` скрипт создаёт парный `.meta.json` с библиографическими полями (`title`, `authors`, `journal`, `year`, `volume`, `issue`, `firstpage`, `lastpage`, `url`, `accessed_date`) — это гарантирует точные сноски без выдумок.
3. **Обработка `[NEED_BROWSER]` (403 / JS-рендеринг):**
   - Если `fetch_sources.py` вывел `[NEED_BROWSER] <url>` (например, JS-рендеринг или защита от простого HTTP-клиента), делегируй открытие страницы субагенту `browser` (сохрани PDF или текст + точные выходные данные в `sources/`).
   - **Важное ограничение безопасности:** если сайт защищён CAPTCHA / «подтвердите, что вы человек» / платным доступом — **НЕ обходи CAPTCHA**. Пропусти проблемный URL и подбери альтернативный открытый источник (другую статью ВАК/РИНЦ, зеркало на сайте университета или другой отраслевой отчёт), либо попроси пользователя скачать/загрузить файл в `sources/` вручную.
4. **Поисковый самоконтроль (Exit Gate 1):**
   Запусти `parse_pdfs.py` с `--contract project_contract.json` — скрипт автоматически проверит:
   - число валидных уникальных источников ≥ `bibliography.min_sources`;
   - долю свежих источников (год ≥ `bibliography.min_year`) и соблюдение лимита классиков (`max_classic_sources`);
   - 0 непереведённых иностранных источников (если `forbid_untranslated_foreign: true`);
   - наличие эмпирических источников с цифрами (проценты, рубли, выборки) для практической главы.
   Пока скрипт возвращает `FAIL` по Exit Gate 1 — запускай новый раунд поиска, не переходя в Фазу 2.
