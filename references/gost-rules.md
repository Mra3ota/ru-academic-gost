# Стандарты ГОСТ для оформления в Microsoft Word (`.docx`)

Основа: **ГОСТ 7.32-2017** (Отчёт о НИР / академические работы), **ГОСТ Р 7.0.5-2008** (Библиографическая ссылка), **ГОСТ Р 7.0.100-2018** (Библиографическое описание). Локальные требования вуза из `project_contract.json` имеют приоритет над значениями по умолчанию.

---

## 1. Параметры страницы, шрифт и абзацы
- **Формат:** А4 (210 × 297 мм), ориентация книжная.
- **Поля:** левое 30 мм, правое 15 мм (или 10 мм по `project_contract.json`), верхнее 20 мм, нижнее 20 мм.
- **Основной текст:** `Times New Roman`, **14 пт**, цвет чёрный (`#000000`), межстрочный интервал **1.5**, интервалы Перед/После абзаца — строго **0 пт**, отступ первой строки (красная строка) — **1.25 см**, выравнивание — **по ширине**.
- **Нумерация страниц:**
  - Титульный лист считается страницей 1, но номер на нём **скрыт** (`different_first_page_header_footer = True`).
  - Видимая нумерация начинается со стр. 2 (Содержание или Введение) внизу по центру (`bottom_center`), `Times New Roman`, 12 пт, без точек и тире.

---

## 2. Заголовки, структура и разрывы страниц
- **Структурные элементы (`Heading 1`):** `СОДЕРЖАНИЕ`, `ВВЕДЕНИЕ`, `ГЛАВА 1. ...`, `ГЛАВА 2. ...`, `ЗАКЛЮЧЕНИЕ`, `СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ`, `ПРИЛОЖЕНИЕ А`.
  - Каждый элемент `Heading 1` начинается строго с **новой страницы** (`page_break_before = True`, **никогда** не пустыми Enter!).
  - Выравнивание по центру (или по левому краю с 1.25 см по методичке вуза), полужирный, TNR 14 пт, **без точки в конце**, отступ первой строки 0 см при центрировании, `keep_with_next = True`.
- **Подразделы / параграфы (`Heading 2`):** `1.1 Название параграфа`, `2.2 Анализ результатов`.
  - Отступ первой строки 1.25 см, полужирный, TNR 14 пт, **без точки в конце**, `keep_with_next = True` (запрет «висячего заголовка» внизу страницы).
- **Анти-хвост (висячие страницы):**
  - На последней странице **каждого** крупного раздела (Введение, Глава 1, Глава 2, Заключение) должно быть **не менее 4 строк основного текста**. Хвосты из 1–3 строк на отдельной странице запрещены.

---

## 3. Ссылки и сноски (два режима)

### Режим A: Постраничные подстрочные сноски (`citations.style = "footnote"`)
- Шрифт текста сноски: `Times New Roman`, **10 пт**, межстрочный интервал **1.0**, выравнивание по ширине, интервал Перед/После **0 пт**, отступ первой строки **0 см** (или 1.25 см по методичке).
- Знак сноски ставится **СЛИТНО** со словом и **ДО** точки или запятой:
  - Правильно: `...эффективности кампании¹.` и `«точная цитата»².`
  - Ошибка: `...кампании 1 .` или `...кампании.¹`
  - Исключение: после `?`, `!`, `...` знак сноски допускается после них.
- **Критическая ловушка `Там же.`:**
  - `Там же.` (или `Там же. — С. 18.`) допустимо **ТОЛЬКО** если предыдущая сноска находится **на той же отрендеренной странице Word**!
  - Если сноска переехала на следующую страницу и стала первой внизу новой страницы, `Там же.` — грубое нарушение ГОСТ. В сомнительных местах используй краткую повторную ссылку (`Иванов И. И. Указ. соч. — С. 18.`), а `audit_docx.py` автоматически проверит PDF на `Там же.` в начале блока сносок каждой страницы!

### Режим B: Внутритекстовые / затекстовые ссылки (`citations.style = "brackets"`)
- В готовом документе: `[14, с. 52]`, `[14, с. 52–53]`, для нескольких источников `[3; 14]`, для электронных ресурсов без пагинации `[19]`.
- **Рекомендуемый способ написания в Markdown (авто-перенумерация v2.0):**
  - В `06_biblio.md` задай теги `[@key]`:
    ```markdown
    [@fz38] Федеральный закон от 13.03.2006 № 38-ФЗ «О рекламе»...
    [@egorov2023] Егоров А. В. Индексные модели... — 2023. — С. 45–52.
    ```
  - В тексте пиши `[@egorov2023, с. 45]` или `[@egorov2023, с. 45; @elkin2024, с. 112]`.
  - При сборке `build_gost.py` сам отсортирует библиографию (НПА → А–Я с `Ё`=`Е` → A–Z) и заменит все ключи на точные номера `[2, с. 45]`, гарантируя 100% совпадение с нумерацией списка!

## 4. Таблицы, рисунки, формулы и приложения
- **Таблицы:**
  - Над таблицей: строка 1 — `Таблица N` (выравнивание по правому краю, без точки, TNR 14 пт, `keep_with_next = True`, красная строка 0); строка 2 — название таблицы (по центру, полужирный, без точки, `keep_with_next = True`, красная строка 0).
  - Альтернативный формат ГОСТ 7.32 в одну строку (`Таблица 1 — Название таблицы` по левому краю) также поддерживается `build_gost.py`.
  - Внутри таблицы: чёткие чёрные границы 0.5 пт, шрифт `Times New Roman` **11–12 пт**, интервал **1.0–1.15**, отступ первой строки **0 см**, шапка таблицы помечена `w:tblHeader` (повтор шапки при переносе), на каждой строке выставлен `w:cantSplit`.
  - Короткие таблицы (≤ 5 строк) удерживаются на одной странице целиком (`keep_with_next` на строках).
  - После таблицы при необходимости: `Источник: составлено автором по данным [..].` (TNR 12 пт).
  - На каждую таблицу должна быть прямая ссылка в тексте выше неё (`...представлены в таблице 1.`).
- **Рисунки и диаграммы (`scripts/make_chart.py`):**
  - Генерируй диаграммы через `make_chart.py` (300 DPI, шрифт Times New Roman, русские десятичные запятые, академическая палитра, без дублирующего внутреннего заголовка).
  - Вставка в Markdown: `![](data/fig_1.png){width=15cm}`, ниже по центру подпись `Рисунок 1 — Название рисунка` (TNR 12 пт, без точки в конце), затем `Источник: ...`.
  - Обязательная ссылка в тексте до рисунка (`...показано на рисунке 1.`).
- **Нумерованные формулы (ГОСТ 7.32):**
  - В Markdown пиши `$$ROI = \frac{D - C}{C} \times 100\%$$ {#eq:1}` или `$$...$$ (1.1)`.
  - `build_gost.py` оборачивает нативную формулу Word OMML в 3-колоночную таблицу без границ: формула строго по центру, номер `(1)` по правому краю.
  - Расшифровка символов даётся сразу под формулой с новой строки словом «где» (без двоеточия, без красной строки или с обычного абзаца по методичке).
- **Кастомный титульный лист вуза:**
  - Если кафедра требует фирменный `.docx` титульник (с логотипом/гербом или таблицей подписей нормоконтроля), передай `--title-template custom_title.docx` (или укажи `layout.title_template_path` в `project_contract.json`). Поддерживаются плейсхолдеры `{{topic}}`, `{{student_name}}`, `{{student_group}}`, `{{supervisor_name}}`, `{{supervisor_title}}`, `{{city}}`, `{{year}}` и др. из `meta.json`.
- **Приложения:**
  - Начинаются с новой страницы после Списка источников; обозначение `ПРИЛОЖЕНИЕ А` (исключая буквы Ё, З, Й, О, Ч, Ь, Ы, Ъ по ГОСТ 7.32).

## 5. Список использованных источников (ГОСТ Р 7.0.100-2018 / 7.0.5-2008)
- **Порядок сортировки:**
  1. Нормативно-правовые акты (НПА) по убыванию юридической силы (Конституция РФ → Федеральные конституционные законы → Федеральные законы → Указы Президента → Постановления Правительства → Приказы ведомств), если `npa_first: true`.
  2. Кириллические источники в строгом алфавите **А–Я** (**внимание:** буква `Ё` сортируется наравне с `Е`, а не в конце/начале таблицы Unicode!).
     - Работы одного автора идут в порядке: сначала единоличные (по алфавиту заглавий или по годам), затем работы в соавторстве.
     - Статьи/отчёты без указанного автора сортируются по первому слову заглавия (без учёта кавычек).
  3. Иностранные источники на латинице **A–Z** в конце списка (только если `forbid_untranslated_foreign: false`).
- **Примеры библиографического описания:**
  - *Статья из журнала:* `Иванов И. И. Оценка эффективности цифровых коммуникаций // Вестник МГУ. Серия 10. Журналистика. — 2024. — № 3. — С. 45–58.`
  - *Книга / учебник:* `Котлер Ф., Келлер К. Л. Маркетинг менеджмент / пер. с англ. — 15-е изд. — СПб. : Питер, 2022. — 848 с.`
  - *Электронный ресурс:* `Индекс доверия медиа в России в 2025 году [Электронный ресурс] // ВЦИОМ : [сайт]. — URL: https://wciom.ru/... (дата обращения: 15.03.2026).`
- **Инвариант биекции:** каждый источник в Списке обязан быть процитирован в тексте, и каждая сноска/ссылка в тексте обязана присутствовать в Списке!
